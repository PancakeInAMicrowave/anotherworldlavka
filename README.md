# Лавка другого мира
Онлайн магазин для приобретения предметов из других миров.

## Постановка контрольной работы №1

Тема контрльной работы №1: "HTML и CSS: разработка многостраничного сайта".

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы;

## Просмотр проекта
Для просмотра проекта перейдите в GitHub Pages деплоймент сайта: https://pancakeinamicrowave.github.io/anotherworldlavka/

Обратите внимание, что GitHub Pages плохо загружает изображения. Для того, чтобы изображения работали на сайте, скачайте проект и откройте `index.html`.
